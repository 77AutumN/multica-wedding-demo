# 演示话术

适用版本：wedding-demo-v0.1.0。每句话明确 @婚宴演示助手；示例短码要换成机器人本次给出的实际码。

1. 销售：“开始新一轮演示。”核对 28 桌、84000 元样例并确认。
2. 销售：“张先生那场婚宴怎么安排的？”机器人实际读回日期、场地、桌数、金额、第 1 版及负责人。
3. 销售：“可能加三桌，要多多少钱？”机器人回答增加 9000 元、合计 93000 元，尚未修改。
4. 销售：“确定加到31桌，新增三桌用无海鲜套餐。”核对预览后发送“确认 六位码”。
5. test：“接收第2版变更。”核对后确认，记录接收。
6. test：“菜单已交接，布桌方案还没核对。”核对后确认，只完成菜单。
7. 任一人：“还有什么没办完？”应指出第2版的布桌方案核对及负责人。
8. test：“第2版布桌方案已核对。”核对后确认，回复本次变更交接完成。
9. 销售开始下一轮。旧轮编号和记录保留，新轮回到 28 桌、第 1 版。

纠正示例：“改成32桌吧。”工具保留原先已说明的 3 桌无海鲜套餐，重算金额并换码；旧码不能保存。

角色：销售只能改订单和开始新轮，test 只能接收与反馈，两人都能查询。任何正式保存都有预览和本人确认。

这是虚构资料，不是实际婚宴合同、食品安全判断、收款记录或真实交付承诺。
